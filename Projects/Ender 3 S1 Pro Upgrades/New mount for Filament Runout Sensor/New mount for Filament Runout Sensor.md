After installing a [[Secondary Spool Holder]] the filament run out sensor was not well placed since it was positioned for the right side spool holder.
![[No secondary spool holder.jpg]]

I needed to have the sensor more centrally located.
# Model
I chose [this model from Printables.com](https://www.printables.com/model/371760-ender-3-s1-pro-dual-filament-sensor-relocation-bra).
![[DualFilamentSensorBracketV1.stl]]
![[Ender 3 S1 sensor bracket.3mf]]

Printing this was done with the back side down and with supports

I evaluated several different models, but settled on this one because it:
- Did not required any new screws other than that which came with the printer
- It had holders to hold the end of the filament that wa not in use
